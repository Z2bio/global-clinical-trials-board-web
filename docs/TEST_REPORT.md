# 测试与审计报告

## 自动化测试范围

1. ClinicalTrials.gov API V2 样例响应标准化。
2. 状态、分期、申办方类型和人数类型中文转换。
3. 干预描述中的疗程时间片段提取。
4. 入选与排除标准自动分段。
5. 常见中文疾病查询词转换。
6. 国家和申办方类型筛选。
7. 当前页排序。
8. GitHub Pages 相对路径与必需文件审计。
9. HTML 中数据来源、免责声明、语义主区域和搜索标识审计。
10. JavaScript 中 `eval` 风险检查。

## 本地执行

```bash
npm run check
```

## 浏览器冒烟测试建议

- 首次打开无缓存：显示加载骨架并请求 API。
- 有缓存重新打开：先显示缓存，随后更新为网络结果。
- 断网重新打开：显示缓存和缓存保存时间。
- 搜索“肺癌”：提示转换为 `lung cancer`。
- 搜索 NCT 编号：能够打开对应详情。
- 状态筛选：重新请求官方 API。
- 分期、国家和申办方：当前页即时筛选。
- 收藏后刷新：收藏仍保留在本地。
- 清除本地数据：查询缓存和收藏均被删除。
- 手机宽度：筛选改为底部抽屉，详情改为全宽底部面板。
